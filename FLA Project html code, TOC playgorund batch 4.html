🧩 Pumping Lemma

Question 1 · Prove the language is not context-free
⌄

Think of a long string as a line of tiles. The lemma says a sufficiently long CFL string can be split into five parts, and two selected parts can be repeated (pumped) together. For the assigned language, every permitted split fails to keep the three block counts equal after a suitable pump.

L = { aⁿ bⁿ cⁿ | n ≥ 1 }
s = aᵖ bᵖ cᵖ
s = u v w x y
|vwx| ≤ p, |vx| > 0
1
Choose a long string
Take s = aᵖbᵖcᵖ, where p is the pumping length.
2
Split into five parts
The window vwx is at most p symbols long, so it cannot cover all three blocks at once.
3
Pump down
Set i = 0, removing v and x. At least one symbol disappears. Since v and x fit within a short window, pumping down disrupts the required equal counts or block order.
Important: the Pumping Lemma is not a stack machine. It is a proof technique about repeating/removing substrings.

Pushdown Automaton (PDA)

Question 2 · Construct a PDA
⌄

A PDA is like a little robot with states and a stack. Every input symbol moves the robot; stack markers are pushed or popped to remember how many symbols still need matching.

L = { 0ⁿ 1³ⁿ | n ≥ 1 }
For every 0 → push 3 markers
For every 1 → pop 1 marker
1
Read the zeros
Each zero adds three markers to the stack.
2
Switch to the ones phase
Once a 1 appears, no more zeros are allowed.
3
Pop one per 1
Accept only when input is finished and all markers have been removed, with at least one zero read.
Quick example: 00 creates 6 markers. The six 1s in 00111111 pop all six, so the input is accepted.
