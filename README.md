# TOC Playground

An interactive web-based learning tool for exploring Theory of Computation (TOC) concepts through visual explanations and simulations.

## Features

- **Learn:** Explore fundamental Theory of Computation concepts.
- **Pumping Lemma:** Experiment with string decomposition, pumping values, and condition checks.
- **Pumping Analysis & Summary:** View decomposition validity, pumping results, and string membership.
- **PDA Simulator:** Explore Pushdown Automata through interactive simulations.

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open the main HTML file in your browser.

No additional installation is required.

## Project Purpose

This project is designed to make Theory of Computation concepts easier to understand through interactive visualizations and hands-on experimentation.
